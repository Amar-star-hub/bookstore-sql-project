
# 📚 Bookstore SQL Data Analysis Project

## 📌 Project Overview

This project analyzes a bookstore database using SQL and PostgreSQL.

The project contains information about books, customers, and orders. SQL queries are used to retrieve, filter, aggregate, and analyze the data to generate useful business insights.

## 🗂️ Project Files

| File            | Description                              |
| --------------- | ---------------------------------------- |
| `project.sql`   | Database tables and SQL analysis queries |
| `Books.csv`     | Book information                         |
| `Customers.csv` | Customer information                     |
| `Orders.csv`    | Order information                        |

## 📊 Analysis Questions

The project answers questions such as:

1. Retrieve all books in the Fiction genre.
2. Find books published after 1950.
3. List customers from Canada.
4. Find orders placed in November 2023.
5. Calculate total book stock.
6. Find the most expensive book.
7. Find orders with quantity greater than 1.
8. Find orders where total amount exceeds $20.
9. List all available book genres.
10. Find the book with the lowest stock.
11. Calculate total revenue.

## 🚀 Advanced SQL Analysis

The project also includes advanced analysis such as:

* Total books sold by genre
* Average price of Fantasy books
* Customers who placed at least two orders
* Most frequently ordered book
* Top 3 most expensive Fantasy books
* Total books sold by author
* Cities of customers spending over $30
* Customers with the highest total spending

## 🎯 Objective

The objective of this project is to demonstrate practical SQL skills for data analysis, including data filtering, aggregation, grouping, and joining multiple tables.
